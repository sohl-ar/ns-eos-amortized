# Local EOS results from November 20, 2026

`outputs/` contains the causality comparison, EOS verification report, and compiled ML4PS paper. `run_v3/` contains additional summaries and figures from the local training run. The paper source and figure-generation script are under [`paper/`](../../paper/).

The training data, model checkpoints, run logs, notebook working files, and validation outputs are available in the [local results release](https://github.com/sohl-ar/ns-eos-amortized/releases/tag/local-results-2026-11-20). The ZIP archives preserve the paths under `neutronstareos/` and `workspace/`. Extract them into the same parent directory, then copy the shared catalog into each path listed in `shared-catalog-paths.csv`. `SHA256SUMS.txt` records checksums for the downloads.
