# Neutron-star EOS verification

Reviewed the local package on November 18, 2026. All 14 repository tests passed. The small end-to-end run reached its summary stage. The production run had saved simulation shards but had no final grid-validation, training, calibration, or posterior-comparison results at the time of review. The checks below ran against the local source and data. Solver variants were evaluated in memory.

## Findings that affect the simulated data

1. **The tidal metric coefficient is fixed in the source. One saved production curve still uses the earlier equation.** I took the first record of the first production shard and recomputed its curve with the default pressure grid. Its saved Λ₁.₄ was 1101.133634. Setting the coefficient to 1 reproduced that value. The current coefficient of 2 gave 1062.690419. A fresh output root or a verified solver-version identifier on every reused shard is necessary for a corrected production dataset.
2. **The crust sound speed disagrees with the pressure–energy-density relation used by TOV.** The crust table uses ε = (P/K)^(1/Γ). Its analytic derivative gives dP/dε = ΓP/ε, while the tidal equation uses ΓP/(ε+P). Independently interpolating Γ and ε across the crust–core join adds a larger local discrepancy. For θ = [1.5, −0.25, 0, 0] at P = 2.9 MeV/fm³, the solver gave 0.0810 for cₛ²/c² and finite-differencing its own energy-density interpolant gave 0.0497. As a sensitivity test, I used the derivative of that interpolant below 3 MeV/fm³ with the current factor of 2 and 30 central pressures. Λ₁.₄ changed from 916.01 to 978.61 for that EOS and from 280.96 to 291.08 for [1, 0, 0, 0]. These are two examples. To choose a production fix, specify the intended crust EOS, implement its derivative consistently on each side of the join, then verify the tidal solution against an independent implementation using the same EOS.

## Findings that affect inference and reporting

| Finding | Evidence and consequence |
|---|---|
| GW likelihood quadrature can miss narrow structure | I took up to the first three GW observations from each of the first 100 saved EOS records, using the exact stored branch for each. Across 218 observations, the median absolute change in log likelihood between the default 16×24 rule and a 64×64 rule was 0.000086. The 95th percentile was 0.00142. For EOS index 154 the default gave −6.88815, 64×64 gave −6.42650, and 128×128 gave −6.42648. The default gives about 37% less likelihood in this case. Test an adaptive or higher-order rule across the supported noise range. The effect on a full catalog posterior remains unmeasured. |
| Raw flow draws can include uniform replacements | After six unsuccessful rejection rounds, the sampler fills missing slots with draws from the uniform parameter box. This changes the distribution being summarized. Record the shortfall and retry or return an explicit failure. |
| Derived intervals mix physical-support outcomes | The summary counts draws failing the exact support check, then includes their finite observables in medians and intervals. A direct call with one failing draw in three confirmed this behavior. Report raw-flow diagnostics separately from intervals conditioned on exact support, and state which distribution each interval describes. |
| Importance sampling needs a failure path | Forcing all ten proposals to have zero target density returned ESS 0 and ten NaN weights. Downstream real-data comparison and resampling assume usable weights. Resampling a small number of effective draws thousands of times also preserves the original low information content. Report insufficient ESS and handle zero weight explicitly. |
| Ensemble cost is understated | Training records the time for all three members. The break-even calculation uses only the first member's time. Use the total ensemble training cost when reporting the headline ensemble. |
| The crust-sensitivity comparison changes the sample | The varied arm drops EOSs failing the new crust acceptance check. The fixed arm keeps every original EOS, and both arms independently draw catalogs. For a paired effect, compare the same surviving EOSs with matched catalog composition and noise draws, and report the change in acceptance separately. |

## Reproducibility and interpretation

- Stage completion markers hash the configuration. Several lower-level data and reference caches are reused by path. A solver source edit alone can therefore reuse products from an earlier equation.
- Dataset generation resumes after the largest returned index from an unordered worker pool. Lower indices still in flight at the checkpoint can be skipped after interruption. Training augmentation also mixes process IDs into the seed. Fixed configuration seeds alone do not reproduce an interrupted run exactly.
- A resumed Dynesty call omits the configured stopping tolerance and call limit supplied to the original call. Pass the intended tolerance on resume and account for calls already consumed if the limit is a total budget.
- The grid is shared by importance sampling and Dynesty. Their agreement tests inference on that grid. Both compute evidence under a uniform box prior with physical rejection in the likelihood. For evidence conditioned on physical acceptance, divide the box evidence by the accepted prior fraction for the same support definition.
- Fisher calculations require every selected mass up to 2 M☉ to lie on the branch. The revised prior accepts EOSs down to 1.5 M☉. Interpret the Fisher result for the branch-covering subset and report how many draws it excludes.
- Both local GW files parsed successfully with 8,078 low-spin samples for GW170817 and 53,945 for GW190425. The likelihood uses Gaussian summaries of those files. Its calibration on simulated catalogs and its adequacy for those observational summaries are distinct scientific questions.

The first two findings affect simulation provenance and tidal labels. The GW quadrature issue can be addressed before generating the reference posteriors. The remaining issues concern sampling, downstream analysis, or reporting and can be handled independently of expensive EOS generation.

Establishing structural non-identifiability requires stronger evidence than a network attaining prior-level errors. Likewise, an EOS posterior under independent Gaussian summaries should be described as conditional on that observational model.
